# Ear Warrior — "hear it / see it / play it back" Short (Remotion)

7 s, 1080×1920, 60 fps. Scenes of 2 s (the cuts are pushes — scenes slide off left/up and the next slides in, `src/Move.tsx`, 16 frames, no flash): **Hear it** (sound contour) → **Every note has a fret** (neck tour) → **Now play it back** (numbered answer markers) → **N/N** result (1 s).

```bash
npm run render -- tunes/turkish-march.json            # → out/turkish-march.mp4
npm run render -- tunes/a.json tunes/b.json           # several in one go
npm run render:all                                    # every tunes/*.json
npm run render -- tunes/x.json --audio-only           # soundtrack only → public/x.wav
npm run dev                                           # Remotion Studio (opens the Turkish March)
npm run typecheck
```

A tune is one JSON file (see the header of `tune.mjs` for the format): `id`, `bpm`, `key`, `listen` (≤ 2 s), optional `tour` (≤ 2 s), optional `chord`, optional `copy` overrides
(hook lines, chip, result line, tagline — `*word*` = accent). Notes are `NAME:BEATS`, optionally pinned to a fret with `@G4`; otherwise the fretting is chosen automatically.
Too long a phrase fails with the number of seconds it needs — raise `bpm` or shorten it.

Sound = the recorded acoustic guitar in `../synth.mjs` + a kick/shaker pulse on `bpm`. Tunes must be public domain; the melodies in `tunes/` were written from memory — **play the render and compare with a recording before posting.**

## "Tabs guy" — 60 s pain sketch

An animated sketch (flat SVG characters, no live actors): a guitarist who plays perfectly from a tab freezes at a party when asked to play without one, and the quiet guy hears the tune once and plays it. Ends on the app's fretboard + `earwarrior.app`.

```bash
node render-pain.mjs                 # → public/ear-pain.wav + out/ear-pain.mp4 (1080×1920, 60 fps, 60 s, ~10 min)
node render-pain.mjs --audio-only    # soundtrack only
npm run dev                          # Studio → composition "Pain"
```

`pain/story.mjs` is the single timeline (scene times, the riff, Ode to Joy attempts with their wrong notes, the second voice). `pain/audio.mjs` and `src/pain/PainVideo.tsx` both read it, so every wrong note is heard when it is seen. Characters: `src/pain/Person.tsx` (two-bone arms that follow the guitar neck, mood-driven faces), sets: `Rooms.tsx`, props and captions: `Items.tsx`, fretboard picture-in-picture: `Inset.tsx`. On-screen text is English. The riff is original; Ode to Joy is public domain. Pitches were generated from the timeline, not listened to — **play the render before posting**.

## Short cut (19.9 s) with narration

`node render-pain.mjs --cut` → `out/ear-pain-cut.mp4` (`--voice` first fetches the narration from voice.ai). It is the same story as the 60 s sketch, compressed, not a different edit: `pain/cut.mjs` lists the spans of the 60 s timeline (`SEGS`: from, to, how long each takes), each played faster so every beat survives (hook → legend → the ask → no tab → three failed starts → the excuse → the quiet guy → CTA). The picture runs the original components through a warped clock (`src/clock.tsx`, `PainCut` in `src/pain/PainVideo.tsx`); the music is laid again from the same note list at the compressed times, so pitches stay put and a wrong note is still heard when it is seen. No synthesized crowd noise (it read as hiss).

Narration: `LINES` in `pain/cut.mjs` (each sits on the caption it reads), generated by the voice.ai TTS API into `pain/voice/` by `pain/voice.mjs`. Key: `AI_VOICE_TOKEN` in `server/.env` (or `VOICE_AI_API_KEY` in a git-ignored `assets/video/remotion/.env`). Default voice is "Ryan" (deepest public male voice, median pitch ≈ 88 Hz vs 119–134 for the others); `VOICE_AI_VOICE_ID` overrides it. Files are named by a hash of voice + text, so editing a line regenerates only that line. The free voice.ai plan has no commercial license — Starter ($5/mo) and up do.

## Animation principles (apply to every new animation)

Checked against the "by ear" film (`src/byear/ByEar.tsx` — the worked example; each principle is tagged where it is used). Motion is always a pure function of time `t`, so any frame renders alone.

- **Anticipation** — a small move the wrong way before the real one (crouch before a jump, lean back before the first note). Ramp it in, then *cut* it the instant the real move starts (`pre`).
- **Squash & stretch** — flatten on impact, stretch in flight, keep volume: `sx = 1 + 0.8·(1 − sy)`. Anchor the scale at the feet, not the centre.
- **Follow-through** — the head/hand is the body's own motion, late: `lean(t − 0.09) − lean(t)`. Eyes lead, head follows, body last.
- **Overshoot** — springs and damped cosines (`wob`) pass the target and settle; never ease to a dead stop. Hand up = one spring, hand down = another.
- **Hold** — after the big beat everything freezes for ~0.3 s (the miss), only a secondary detail moves (sweat drop). Pauses are the joke.
- **Secondary action** — things that sell the main move: speaker cone, sound waves, flying notes, ring on arrival, camera push + decaying shake, light on the payoff.
- **Never perfectly still** — breathing (≈2 px, 3.6 s), blinks, a slow camera drift.
- **Sound lands on the frame** — one timeline file (`story.mjs`) drives audio and picture; impacts get a sound, wind-ups a rising whoosh.

Helpers (copy from `ByEar.tsx`): `kick` (decaying hit), `wob` (damped cosine), `hump` (jump arc), `pre` (wind-up that cuts), `kf` (eased keyframes).

## "By ear" — 5 s (example)

He listens to a phrase (hand cupped to the ear), then works it out on the guitar: one wrong note, a held beat, the fix, a strummed chord.

```bash
node render-byear.mjs                # → public/by-ear.wav + out/by-ear.mp4 (1080×1920, 60 fps, 5 s, ~15 s to render)
node render-byear.mjs --still=3.15   # one PNG frame at that second → out/frames/
npm run dev                          # Studio → composition "ByEar"
```

`by-ear/story.mjs` is the timeline (heard notes, played notes incl. the miss, chord) and drives both `by-ear/audio.mjs` and the picture. `Person` gained two optional props for this: `guitar.ear` (hand to the ear) and `head` (head moves independently of the body). The rendered files were deleted; re-render with the command above.
