# Библиотека мелодий v2: 100 целых мелодий, по сложности

Черновик для утверждения состава (2026-11-06). Ноты ещё не сняты, поэтому «≈нот» и порядок
внутри уровня — оценка по памяти. После того как каждая мелодия будет снята с настоящей партитуры
(не с буквенных табов), порядок пересчитывается по формуле ниже.

## Правила

1. **Целая мелодия.** Законченное высказывание, которое узнают и которое кончается на тонике:
   песня — куплет и/или припев целиком; классика — главная тема целиком (период), не вся пьеса.
2. **Без повторов.** Каждая мелодия встречается один раз во всей библиотеке, на одном уровне.
   Выкинуты одинаковые мелодии под разными названиями: Baa Baa Black Sheep и ABC Song (= Twinkle),
   Brother John (= Frère Jacques), Glory Glory (= Battle Hymn).
3. **Публичное достояние.** Композитор умер в 1955 году или раньше, мелодия издана до 1930 года;
   у народных мелодий автора нет. Не прошли: Bella ciao (происхождение спорное), Катюша, Подмосковные
   вечера, Танец рыцарей (1938), Танец с саблями, O Fortuna (Орф †1982), Wheels on the Bus (1939),
   булерия Сеперо.
4. **Без лимита на число нот.** Длина — один из признаков сложности, а не рамка уровня.
5. Всё транспонируется в гриф E2–E5 (12 ладов).

## Как считается сложность

- **Звукоряд** (главная ось, решение от 2026-10-11): П — мажорная пентатоника,
  Д — ноты одной тональности (мажор или натуральный минор), Х — есть ноты вне тональности.
- **Длина**: сколько нот надо найти.
- **Диапазон и скачки**: ход шагами проще, чем скачки на кварту и шире.
- **Плотность**: быстрые шестнадцатые и мелизмы на слух разбирать труднее, хотя ритм не оценивается.

## Состояние (2026-11-06)

Код и библиотека готовы, тесты зелёные, в приложение ещё не выкачено.

- Источник мелодий — `src/services/melody/library.abc` (ABC, по блоку на мелодию: `%%id`, `%%level`,
  `%%source`, свой темп `Q:`). `npm run library` собирает из него `library.ts`, который читает приложение.
- Лимита на число нот больше нет: уровень у каждой мелодии задан явно, от 16 до 96 нот.
- Темп у каждой мелодии свой (от ♩ 50 до ♩ 220), источник записан в `%%tempo`: метроном автора, где он есть
  (Бетховен, Дворжак, Бизе, Равель, Шопен), иначе словесная пометка + типичное исполнение или темп исходного MIDI.
- Звук: записанная нейлоновая гитара (FreePats Spanish Classical Guitar, CC0) через fluidsynth, а не синтез.
  Клипы `assets/app/audio/melodies/<id>.m4a` (100) и ноты грифа `assets/app/audio/notes/` (37), ≈33 МБ.
- Источники нот (2026-11-06, второй проход): 72 мелодии сняты с партитур (Mutopia Project, MIDI с
  Wikimedia Commons, LilyPond из Википедии и Викиучебника), 2 частично, 26 — по памяти (открытых нот не нашлось),
  владелец проверил их на слух (hotcrossbuns, mary, newworld, bridal, morning, yankee, range, kalinka, hope, swan, granvals, jesu, tell, donna, valkyries, cancan, aida, sugarplum, nutmarch, humoresque, solemio, nessun, babbino, theswan, hungarian5, badinerie).
- Проверка на слух: `docs/melody-check.md` (`server/node_modules/.bin/tsx scripts/melody-check.ts`).
  Сначала идут мелодии, записанные по памяти, — их надо проверить в первую очередь.
- Пересборка аудио после правки нот: `scripts/export-library.ts` → `assets/guitar-rig/render_library.py`.
