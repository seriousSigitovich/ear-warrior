# Выход гладиаторов — табы (#80)

Юлиус Фучик, «Выход гладиаторов» (1897), первая тема целиком, как в видео #80: 87 нот, первая позиция, лады 0–4. ♩ = 200, такт 4/4. Один дефис соответствует восьмой ноте, на шаг даётся три символа.

Такты 9–12 повторяют такты 1–4. Последнюю C можно взять аккордом C (x32010).
